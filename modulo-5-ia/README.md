# Módulo 5 · Os projetos com Claude Code

Um backlog real dos Projetos Kabum e G1 entregue com um agente de código, aula a aula: como ele trabalha, as regras do projeto (`CLAUDE.md` e permissões), o modelo por tarefa com o custo medido, subagentes e worktrees, ganchos e um servidor MCP do banco, issues disparadas por roteiro, e o caminho gratuito com um modelo do Ollama.

- `backlog/`: as seis issues, o commit do colega (`colega.patch`) e o exercício da instrução escondida (`plantar.sql`).
- `agentes/`: o roteiro que dispara issues com `claude -p` e o que pergunta ao modelo local.
